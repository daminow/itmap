# Публикация справочника

Основной адрес: https://daminow.github.io/itmap/. Домен itmap.daminov.net выполняет постоянный редирект с сохранением пути и параметров.

Продакшен-сборка с `VITE_BASE_PATH=/itmap/` создаёт карту, справочник, страницы направлений и профессий, страницы о данных и приватности, sitemap.xml и настоящую 404.html. В sitemap входят только канонические страницы. Поиск, фильтры и выбранные роли не создают отдельные индексируемые страницы. HTML содержит текст, ссылки, уникальные заголовки и описания до выполнения JavaScript.

Данные берутся из src/data/registry.ts; содержимое страниц, количество профессий и карта сайта обновляются при сборке. Не добавляйте дату актуальности зарплат без проверяемого исследования. Справочник объясняет ограничения оценок на странице about/.

Основные проверки: `npm run lint`, `npm run typecheck`, `npm test`, `VITE_BASE_PATH=/itmap/ npm run build`. Для предпросмотра используйте тот же VITE_BASE_PATH. GitHub Actions публикует только успешную сборку основной ветки.

Счётчик public/analytics.js отправляет события в Daminov Analytics под именем itmap.daminov.net. При обновлении файла сборка пересчитывает SRI и версию скрипта. Он учитывает DNT/GPC, не использует аналитические cookies и не отправляет поисковые параметры. Повторы одного события устраняет уникальный event_id на приёмнике. Статическая 404 закрыта от индексации.

Sitemap: https://daminow.github.io/itmap/sitemap.xml. Для управления индексацией добавьте этот адрес в Google Search Console и Яндекс Вебмастер с аккаунта владельца. Файл robots.txt проекта не управляет всем доменом github.io; правила роботов определяются на корне хоста. Наличие корректных страниц и sitemap не гарантирует срок индексации или позицию в выдаче.

После успешной публикации workflow отправляет канонические адреса из действующего sitemap в IndexNow через Bing. Участники протокола обмениваются такими уведомлениями. HTTP 200 означает получение адресов, HTTP 202 — ожидание проверки файла владения; эти ответы не подтверждают индексацию. Сбой уведомления не отменяет работающий сайт. Для проверки конфигурации без отправки используйте `node scripts/indexnow.mjs --validate-only`. Файл владения в public предназначен для открытой проверки поисковиками, область действия ограничена каталогом /itmap/.
